# 🧠 Website Pembinaan Pelatihan P3K

Proyek ini merupakan sistem berbasis web yang dirancang untuk mengelola informasi pelatihan dan pembinaan P3K secara efisien.  
Aplikasi ini mencakup fitur chatbot interaktif, halaman admin yang dinamis, serta integrasi API dan database untuk mendukung pengelolaan data pelatihan secara real-time.

---

## 🚀 Fitur Utama

- 💬 **Chatbot Interaktif**  
  Mengintegrasikan chatbot berbasis API menggunakan **JavaScript** untuk memberikan respons otomatis terkait informasi pelatihan dan fasilitas.

- 🧩 **Halaman Admin Dinamis**  
  Dibangun menggunakan **React.js** dengan komponen **Bootstrap** serta **Axios** untuk pengambilan data API dari server, memudahkan pengelolaan konten dan data.

- ⚙️ **RESTful API Backend**  
  Dikembangkan menggunakan **Express.js** untuk menangani permintaan data dari sisi frontend dan mengelola logika bisnis aplikasi.

- 🗄️ **Desain Database Efisien**  
  Merancang dan mengoptimasi struktur database untuk mendukung kebutuhan dinamis sistem pembinaan pelatihan P3K.

- 🌐 **Deployment & Domain Configuration**  
  Melakukan konfigurasi domain dan deployment melalui **cPanel**, termasuk pengaturan **SSL Certificate** dan optimasi performa server agar website dapat diakses secara stabil.
